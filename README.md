# Traslados Privados Calafate

Sitio web estático (HTML + CSS + JS, sin compilación) para Traslados Privados Calafate, El Calafate, Santa Cruz.

- `index.html`: página completa (ES / EN / PT).
- `img/`: fotos optimizadas en WebP. Las fotos de flora y fauna son de Wikimedia Commons (CC BY / CC BY-SA): mantener los créditos visibles en la página.

Publicación: Vercel, framework "Other", sin comando de build.
